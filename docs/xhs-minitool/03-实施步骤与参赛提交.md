## M9 · 上传与审核（小红书创作服务平台）

按截图页面顺序执行：

1. **左侧「小工具」→ 创建/上传**
2. **第一步 填写小工具包**：上传 `.zip`（根目录必须有 `index.html`；总大小 ≤ 30MB）
   - 建议文件名 `codelex-xhs-v1.2.0.zip`
   - ⚠️ zip 不要多套一层目录（`index.html` 要在压缩包根）
3. **第二步 上传资源文件**：上传 `xhs-minitool/release/icon-512.png`（512×512，4.6 KB）
4. **版本号**：`1.2.0`
5. **手机权限**：只勾 **相册**；其余（设备信息/设备方向）不勾
6. **基础信息**
   - 名称：`CodeLex 程序员英语`（≤ 页面字数限制，不含极限词）
   - 简介：一句话说清"16 技术栈 7859 词 + 310 篇中英对照文章 + SRS 复习，离线可用"，不写外链/联系方式
7. **提交审核** → 等待结果（1–7 个工作日）
8. 驳回 → 按驳回理由整改 → 重新提审

> **已被驳回两次，理由完全相同**（"小工具功能缺陷，可能是页面按钮无法点击"）：
> - v1.0.0：根因是 L1 数据运行时脚本注入被拦截 + 加载态无退出路径 → v1.1.0 修复

> **v1.2.0 复审前务必先在创服平台模拟器验证 tabBar 能切页。** 若仍不过，要求审核方提供具体页面与操作步骤截图，并附上设置页「运行诊断」卡片截图，不要继续盲改。详见 `02-技术实现文档.md` §14 §15。
