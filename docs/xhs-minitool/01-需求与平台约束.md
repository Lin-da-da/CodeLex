# CodeLex 小红书小工具版 · 需求与平台约束（PRD）

> 版本：v2.0（小工具路线）｜ 日期：2026-10-24 ｜ 状态：待决策
> 目标场景：WorkBuddy「1024 造物挑战」程序员节应用创作大赛 → 作品形态选「小程序应用」→ **以小红书小工具（离线 H5 zip）形式发布**
> 基线：CodeLex 网页版（Next.js 14，`C:/IdeaProjects/english`）已核实源码

## 0. 三条必须先接受的结论

1. **技术路线变了**：微信小程序（云开发 + 同声传译插件 + 审核发布）**不能**用于参赛。大赛要求「小程序应用」必须走小红书创作服务平台的「小工具」上传 zip，运行在**完全离线沙箱**里（无网络请求、无后端、无云函数）。此前 `docs/miniprogram/` 的四份文档仅作备选保留，**不适用于本次参赛**。
2. **"功能完全一样"做不到，只能"主体等价 + 4 项降级"**：AI 模拟面试（需 LLM 联网）、跟读打分（需云端 ASR）、复制/导出文件（剪贴板与下载均被禁用）、登录与多账号（无后端）在小工具里**物理不可实现**。24 项功能中 18 项可 100% 等价，4 项降级、2 项移除（详见 §3）。
3. **体验链接不是小工具链接，而是一条「挂了小工具的公开笔记」**：上传后需审核通过 → 发布笔记并挂载小工具 → 复制**笔记链接**提交大赛。链接打不开或审核未过 = 无效作品。

## 1. 平台铁律（来自官方能力清单，逐条硬约束）

| 维度 | 规则 | 对 CodeLex 的直接后果 |
|---|---|---|
| 网络 | **禁止一切网络请求**（`fetch`/`XHR`/外链图片/字体/媒体） | 词库/文章/专项数据全部打包；AI 面试不可用；无 CDN |
| 后端 | 无（纯本地） | 无登录、无云同步、无服务端评分 |
| 脚本 | 必须外置 `.js` + `<script src>`；**禁内联 `<script>`、`onclick=`、`javascript:`、`eval`、`new Function`、WASM** | 事件全部 `addEventListener`；不能引 WASM 库（含 ASR/压缩模型） |
| 兼容基线 | **ES2017 / Chrome 61**（Android 8.1 WebView 61，iOS ≥ 18.4） | 需降级 `?.`/`??`/`Array.flat`/`Object.fromEntries`；**CSS `gap`（flex）不支持**、`aspect-ratio`/`backdrop-filter`/`clamp()` 不可用 |
| 剪贴板 | `navigator.clipboard`、`execCommand` **禁用**；长按菜单禁用 | "复制模板/复制导出" 不可用 → 改存图或去掉 |
| 下载 | `a[download]`、blob 下载 **禁用** | Markdown/CSV/Anki 导出不可用 → 改「Canvas 存相册」或移除 |
| 窗口 | `window.open`、`target="_blank"`、站外跳转 **禁用** | 所有跳转走内部 hash 路由 |
| iframe / Worker / WebSocket / WebRTC / SSE | 全部禁用 | 不能嵌视频、不能后台计算 |
| 文件类型白名单 | `.html .css .js .png .jpg .jpeg .gif .webp .svg .woff .woff2 .json` | **不能打包 mp3/wav** → 朗读只能靠 `speechSynthesis`（需真机实测） |
| 媒体 | 图片只接受 `data:` base64 / 本地路径 | 图标用 inline SVG / emoji，避免位图撑体积 |
| 存储 | `localStorage`/`IndexedDB` 可用、按小工具隔离、**不保证永久** | 学习数据可能被清；需做"导出备份"提示（但导出能力受限） |
| 入口 | 必须有且只有一个 `index.html` | 单入口 + hash 路由 |
| 体积 | 上传 zip ≤ 30MB（页面提示），单文件另有限制 | 全量数据 ~5.9MB 文本 → zip 预计 1.6–2.0MB，容量不是瓶颈，**首屏解析才是** |
| 端能力 | 仅 `postNote` / `saveImageToPhotosAlbum` / `writeTempFile` | 分享只能"唤起笔记发布页"；导出只能"存相册" |
| SDK | `window.xhs.miniTool` 仅容器内注入，浏览器预览为 `undefined` | 必须判空 + 降级，不能裸调 |

## 4. 降级方案（必须写进产品文案，不能"假装有"）

| 被降级能力 | 原实现 | 小工具方案 | 用户感知 |
|---|---|---|---|
| AI 模拟面试 | WorkBuddy Cloud SDK 调 LLM | **题库模面**：从 BQ30/追问45/口述78 组卷，逐题给"参考要点"，不评分、不生成点评 | 入口保留，明确标注"离线题库版" |
| 跟读打分 | `SpeechRecognition` + Levenshtein | **录音回听自评**（`getUserMedia` 可用，但不做识别）；或直接给"三档自评" | 无分数，只有自评 |
| 复制模板/文本 | `navigator.clipboard` | 文本可选中（选择不受限），但长按菜单被禁 → 提供「存为图片」(Canvas → 相册) | 需存相册再看 |
| 导出 MD/CSV/Anki | Blob 下载 | 「导出学习卡片」Canvas 出图 → `saveImageToPhotosAlbum`，或用 `postNote` 发笔记 | 变成图片/笔记 |
| 登录/多账号 | 本地账号 + `scope` 隔离 | 移除；单机单用户 | 无登录概念 |
| 朗读 TTS | Web Speech API | 继续用 `speechSynthesis`（未在禁用清单），**必须**特性检测 + 首次点击预热 + 失败静默置灰 | 可用性待真机验证 |

## 5. 体积与性能预算（实测数据，非估算）

| 项 | 实测 | 说明 |
|---|---|---|
| 词条全量详情 | **4,624 KB** | 7859 词 × 11 字段（含 defEn/codeExample/exampleSentence(s)/tags） |
| 精简索引（term/stack/phonetic/pos/defCn/freq） | **506 KB** | 数组化编码后 |
| 文章（310 篇，运行时口径） | **559 KB** | 去缩进后 |
| 专项（句型/口述/BQ/追问/发音/写作/岗位） | **251 KB** | |
| 合计 | **≈ 5.9 MB 文本** | zip deflate 预计 1.6–2.0 MB（上传上限 30MB，不紧张） |

**真正的瓶颈是首屏解析，不是包体**：5.9MB 文本全量解析在中低端 Android 上约 400–900ms、常驻堆 15–25MB。

| 指标 | 目标 | 红线 |
|---|---|---|
| 首屏可交互（首页） | ≤ 1.5 s | 2.5 s |
| 搜索首字响应 | < 100 ms | 300 ms |
| 翻卡/答题交互 | 无明显掉帧 | 卡顿超 200ms |
| 内存峰值 | < 120 MB | 200 MB |
| zip 体积 | < 5 MB | 30 MB |

> **【2026-10-25 修正】原结论"必须分层加载"已推翻。**
> v1.0.0 采用 L0 静态 + L1 运行时按需注入，结果**被审核驳回**（按钮疑似不可点）——动态注入在容器沙箱/CSP 下不可靠，`loadDict` 不 resolve 会让 9 个页面永久停在"加载中…"。
> 实测 V8 解析全部 4.43 MiB 数据脚本仅 **1.4ms**（低端 Android 8.1 WebView 预计几十毫秒级），全量静态的首屏成本远低于预估，因此 v1.1.0 改为**全量静态引入**：22 个数据脚本全部写在 `index.html`，`app.js` 执行前 `window.__CLX_*` 必然就绪，**页面不存在任何 loading 态**，从根上消除该单点故障。
> 分层的实际收益（省 4 MB 解析）远小于其风险（注入失败 = 功能全废），故不再采用。详见 `02-技术实现文档.md` §14。

## 6. 审核与合规红线

1. **不申请多余权限**：上传页"手机权限"仅有 相册/设备信息/设备方向。默认**只勾"相册"**（用于存图），其余不勾；不要用麦克风（否则能力声明与简介需一致，且与"跟读打分已降级"矛盾）。
2. **零外链**：不出现二维码、微信号、QQ 群、网址、`target="_blank"`；简介也不写"访问 xxx 体验"。
3. **内容合规**：310 篇文章保留 `license` 字段展示；技术内容中的示例代码不得含真实密钥/内网地址；不得出现测试数据、占位符（如 `TODO`、`lorem ipsum`、`xxx`）。
4. **AI 相关**：既然 AI 面试已改为题库版，**不要**在名称/简介里宣称"AI 模拟面试""AI 评分"，避免"生成式 AI 无备案"的驳回点。可写"题库模拟面试"。
5. **命名**：小工具名称需与功能一致，禁用"官方/第一/最/国家级"等极限词；建议 `CodeLex 程序员英语`。
6. **不诱导**：不写"关注领取""分享解锁""点赞查看"。
7. **数据风险提示**：本地存储不保证永久，设置页需注明"数据仅存本机，清理缓存/重装会丢失"。
8. **禁止**：支付、会员、抽奖、社交关系链、UGC 发布（除 `postNote` 唤起笔记）。

### 7.1 作品介绍模板（可直接改）

> CodeLex 是一个面向程序员的英文学习工具：把 16 个技术栈的 7859 个术语、310 篇中英对照技术文章、60 组面试句型与 78 段 60 秒口述脚本装进手机，完全离线可用。
> 目标用户是准备英文面试、需要读英文文档的研发同学。核心玩法是「每日一词 → 10 题测验 → SRS 间隔复习」的闭环：测验错词自动进错题集，收藏的词自动回流复习队列，连续学习天数与掌握度在统计页可视化。
> 体验方式：打开笔记中的小工具即可，无需登录、无网络也能刷词；在「每日」页点词卡听发音，在「文章」页点任意英文单词可即时查义并标记生词。
> 预期结果：坚持 14 天可覆盖一个技术栈的高频词，并能在模拟面试题库中完成一轮英文作答。

## 8. 验收标准

1. §3 矩阵中 18 项 ✅ 逐条通过真机用例；4 项 🟡 的降级路径可用且文案已说明；2 项 ⛔ 入口已移除或替换。
2. 飞行模式下全部功能可用（本身即离线，用"关 WiFi + 飞行模式"验证不触发任何网络错误）。
3. 两端同日期"每日一词"一致；同一组 SRS 评级序列的 `ease/interval/due` 与网页版逐字段相等。
4. `zip ≤ 5MB`、首屏 ≤ 1.5s、搜索 < 100ms。
5. 在 **Android 8.1/Chrome 61 基线真机**（或等效低版本 WebView）无 JS 报错、无布局错乱（重点查 flex gap）。
6. 网页版零改动：`git status` 仅新增 `xhs-minitool/`、`scripts/export-xhs-data.mjs`、`docs/xhs-minitool/`。
7. 上传 → 审核通过 → 笔记挂载 → 笔记链接可在**未关注该账号的账号**下公开打开。
